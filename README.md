# Autocorrect Fail

> Texted my wife I'd pick up the kids after work — autocorrect changed it to 'I'll pick up the kinks' and sent it to the school group chat.

One text, one wrong word, the worst possible audience. "Kids" became "kinks", and the school group chat will never let me forget it.

## How it works

`main.ts` writes the single line above to `entry.txt` in `MAKEFUN_OUTPUT_DIR` (default `/output`). It gates the output before writing: exactly one line, 1–199 characters, no trailing newline, no surrounding whitespace. No network calls, no Python, no files written next to the script.
